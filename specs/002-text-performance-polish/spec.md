# Feature Specification: 文字表示・操作応答改善

**Feature Branch**: `main`

**Created**: 2026-07-26

**Status**: Draft

**Input**: User description: "文字化けを改善したい。全体的にもっさりしている動きをスムーズにしたい。必要であればツールやフレームワークの変更も許容する。"

## User Scenarios & Testing

### User Story 1 - 日本語を正しく読める (Priority: P1)

プレイヤーは、iPhoneへインストールしたPWAを含む対象環境で、ゲーム内の日本語、数字、記号を文字化けや欠落なしに読める。

**Why this priority**: 数字、危険表示、目的、所持品などを正しく読めないと、推理と探索が成立しないため。

**Independent Test**: オンラインとオフラインの両方で主要画面を開き、表示される日本語と重要記号を期待値一覧と照合する。

**Acceptance Scenarios**:

1. **Given** 初回ロードを完了したiPhone PWA、**When** タイトル、拠点、エリア選択、装備、探索、結果、設定の各画面を表示する、**Then** 日本語、英数字、句読点が欠落や別文字への置換なく表示される。
2. **Given** オンラインで一度起動済みのPWA、**When** オフラインで再起動する、**Then** オンライン時と同じ字体と文字内容が表示される。
3. **Given** 危険マーク、処理状態、死亡地点などの重要情報、**When** 対象端末で表示する、**Then** 端末固有の絵文字や未対応文字がなくても意味を識別できる。

---

### User Story 2 - 探索を滑らかに操作できる (Priority: P1)

プレイヤーは、連続移動、8方向の方向転換、カメラ追従、採掘、危険物処理を、目立つ停止や入力遅延なしに操作できる。

**Why this priority**: 移動と推理を繰り返す中核ループで引っ掛かりが生じると、操作ミスとプレイ意欲の低下につながるため。

**Independent Test**: 自動生成した探索マップで30秒以上連続移動し、採掘と危険物処理を繰り返して、フレーム時間と入力反応時間を測定する。

**Acceptance Scenarios**:

1. **Given** 通常の探索状態、**When** プレイヤーが連続して8方向へ移動する、**Then** キャラクターとカメラが急停止や大きな位置飛びなく追従する。
2. **Given** 壁または危険マスに隣接している、**When** 採掘、危険マーク、危険物処理を行う、**Then** 結果が100ミリ秒以内に画面へ反映され、次の入力を受け付ける。
3. **Given** 100回以上の移動とアクションを実行した探索、**When** 操作を継続する、**Then** 開始直後と比べて継続的な描画速度低下や入力遅延の増加が発生しない。

---

### User Story 3 - 安全に中断・再開できる (Priority: P2)

プレイヤーは、滑らかさの改善後も、アプリ終了、バックグラウンド移行、オフライン起動から直前の確定済み探索状態を再開できる。

**Why this priority**: 表示や速度を改善するために探索進行や既存セーブの信頼性を損なってはならないため。

**Independent Test**: 移動、採掘、危険処理、死亡、チェックポイント到達の各時点でアプリを終了し、再起動後の状態を確認する。

**Acceptance Scenarios**:

1. **Given** 採掘、危険物処理、死亡またはチェックポイント到達が完了している、**When** アプリを終了して再開する、**Then** 完了した結果が失われず復元される。
2. **Given** プレイヤーが移動中、**When** アプリがバックグラウンドへ移行する、**Then** 最後に確定したマスまたはその直後の有効な位置から再開できる。
3. **Given** 既存versionの正常なセーブデータ、**When** 改善後のゲームを初めて起動する、**Then** 既存の進行、設定、探索中断データを引き続き利用できる。

### Edge Cases

- 初回起動中に通信が切断され、表示に必要な資源を取得できない。
- 端末が特定の記号または字体を利用できない。
- 低電力モード、メモリ不足またはバックグラウンド復帰によって描画間隔が大きく変動する。
- 入力中に自動保存、死亡処理、チェックポイント確定または画面遷移が発生する。
- 最大サイズの難易度で、数字、危険マーク、モンスター、落とし物が同時に多数表示される。
- 320px幅の画面、ノッチ、ホームインジケーターがある端末で表示する。
- 軽減モーション設定が有効な状態で、操作反応を損なわず演出を抑制する。

## Requirements

### Functional Requirements

- **FR-001**: システムは、すべてのプレイヤー向け日本語を対象端末で判読可能に表示しなければならない。
- **FR-002**: システムは、初回ロード完了後、オフラインでもオンライン時と同じ文字内容を表示しなければならない。
- **FR-003**: システムは、危険、処理状態、死亡地点などの重要情報を端末依存の絵文字または単一記号だけで表現してはならない。
- **FR-004**: システムは、開発環境から取り込まれる文字データについて、不正な文字コード、置換文字、既知の文字化け列を検出できなければならない。
- **FR-005**: システムは、移動速度とカメラ追従を端末の描画間隔が変動しても一貫して維持しなければならない。
- **FR-006**: システムは、状態変更時に変更されていない画面要素を不必要に再生成してはならない。
- **FR-007**: システムは、画面外のダンジョン要素が表示中の操作応答を継続的に低下させないようにしなければならない。
- **FR-008**: システムは、探索中の保存処理によって連続移動または通常アクションを目立って停止させてはならない。
- **FR-009**: システムは、採掘、危険処理、死亡、チェックポイント確定、探索終了およびアプリのバックグラウンド移行時に、必要な探索状態を保存しなければならない。
- **FR-010**: システムは、通常プレイに影響しない方法で、フレーム時間、入力反応時間、表示要素数、保存所要時間を検証できなければならない。
- **FR-011**: システムは、既存のゲームルール、操作結果、画面遷移、難易度および自動生成結果の意味を維持しなければならない。
- **FR-012**: システムは、既存の正常な永続セーブと探索中断セーブをそのまま読み込めなければならない。
- **FR-013**: システムは、320〜430px幅の縦画面、safe-area、タッチ、ポインター、キーボード入力への既存対応を維持しなければならない。
- **FR-014**: システムは、軽減モーション設定が有効な場合、不要な反復演出を抑制しながら操作結果を即時に提示しなければならない。

### Scope Boundaries

- マインスイーパーの数字、危険物、移動、戦闘、死亡回収、チェックポイント、難易度のルール変更は対象外とする。
- 新しいエリア、アイテム、敵、課金要素、オンライン機能の追加は対象外とする。
- 表示基盤の全面置換は、既存基盤で成功基準を満たせないことが測定によって確認された場合のみ、後続の独立機能として検討する。

### Constitution Requirements

- **CR-001 — Core loop**: 推理、移動、採掘、危険処理、戦闘、回収、領域拡張、深部進行の意味と成立条件を変更しない。
- **CR-002 — Danger and recovery**: 周囲8マスの数字整合性、開始地点の安全性、死亡地点の落とし物と回収可能性を維持する。
- **CR-003 — Adaptive UI/PWA**: 320〜430pxの縦画面、safe-area、44px以上の主要操作領域、12px以上の重要文字、初回ロード後のオフライン起動を維持する。
- **CR-004 — Save compatibility**: 永続セーブと探索中断セーブのversionおよび意味を変更せず、既存データを移行なしで読み込める状態を維持する。
- **CR-005 — Verification**: 文字整合性、移動、カメラ、差分表示、保存タイミングのユニットテストと、3画面幅、オフライン再開、iPhone PWA相当のE2Eまたは実機検証を必須とする。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 対象となる主要画面で、文字化け、欠落文字、意図しない置換記号が0件である。
- **SC-002**: 30秒間の通常探索で平均55fps以上を維持し、95%のフレームが25ミリ秒以内に完了する。
- **SC-003**: 移動方向変更、採掘、危険マーク、危険物処理の95%以上が100ミリ秒以内に視覚反映される。
- **SC-004**: 100回の連続操作後における平均フレーム時間の悪化が、開始時と比べて10%以内である。
- **SC-005**: 通常の採掘または危険物処理によって100ミリ秒を超える操作停止が発生しない。
- **SC-006**: 初回ロード済みのPWAがオフラインで5秒以内に起動し、保存済み探索を再開できる。
- **SC-007**: 既存のユニットテスト、生成ソークテスト、主要E2Eがすべて成功し、既存のゲーム進行に回帰がない。
- **SC-008**: 320×844、390×844、430×932の各表示で、重要文字、HUD、操作領域が欠けたり重なったりしない。

## Assumptions

- 最優先環境はiPhoneのホーム画面へ追加したPWAである。
- 最優先の操作は探索中の連続移動、カメラ追従、採掘、危険物処理である。
- 文字化けという表現には、文字コード破損、未対応字体、欠落記号、端末依存記号の不統一を含む。
- 既存のアート方向性、縦画面方針、ゲームバランス、セーブ内容を維持する。
- 既存基盤の責務分離と差分更新によって成功基準を満たせることを既定とする。
- 実機でのみ再現する問題は、検証用の測定結果と画面記録を使って再現条件を特定する。
